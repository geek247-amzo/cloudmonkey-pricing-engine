# CloudMonkey SEO Audit

Date: 2026-07-17

## Executive summary

CloudMonkey has a sound server-rendered public site, unique canonical URLs, crawlable pricing fallbacks and clear service lanes. The main organic-search constraints were incomplete discovery files, generic title targeting, minimal structured data, limited question-led content and no established editorial resource hub.

The immediate release closes the technical discovery gaps, adds organisation and website schema, adds visible FAQ content and FAQ schema to core service lanes, and aligns core metadata with South African commercial search intent.

## Content roadmap

1. Publish dedicated pages for Managed Server, VPS Hosting, Backups, Monthly Website Packages, Ecommerce Development, AI Automation, AI Voice Agents and Hosted PBX.
2. Publish one evidence-backed case study per primary service lane. Obtain written permission and avoid unverified performance claims.
3. Create a resource hub with practical South African buyer guides, beginning with VPS sizing, website package comparisons, POPIA-aware AI adoption, domain ownership and hosted PBX migration.
4. Add unique team expertise and authorship to technical articles.
5. Connect Google Search Console and Bing Webmaster Tools, submit the sitemap, and record a pre-release baseline.
6. Track organic landing-page sessions, non-brand impressions, qualified leads, proposal starts and assisted revenue monthly.

## Measurement requirements

Information required before performance can be assessed:

- Current Google Search Console property and user access
- Current Google Analytics property and conversion configuration
- Existing ranking and backlink history
- Approved client logos, testimonials and case-study evidence
- Target cities or regions beyond national South African coverage
- Search lead value and closed-revenue attribution rules
